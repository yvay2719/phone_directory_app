# phone_directory_app
A telephone directory application using the Qt library
Задача 0: ПОДУМАТЬ КАК СТРУКТУРИРОВАТЬ КОД, Название и назначение классов.
Задача 1: Написать программу без QT, и данные контрактов хранить в файл.
Задача 2: Добавить графический интерфейс помощью QT. Не удаляя хранение в файл, добавить новую возможность для хранения данных в базе данных (postgresql). Выбор между хранением контактов в файлах или в бд надо определять либо конфигурационным файлом, либо функцией main, либо во время сборки.
Обязательные поля для хранения: Имя, Фамилия, Отчество, адрес, дата рождения, email, телефонные номера (рабочий, домашний, служебный) в любом количестве.
Обязательные поля для создания контакта: Имя, Фамилия, email, 1 номер.
Организовать проверку всех вводимых данных на корректность при помощи регулярных выражений
Фамилия, Имя или Отчество --- должны содержать только буквы и цифры, а также дефис и пробел, но при этом должны начинаться только на буквы, и не могли бы оканчиваться или начинаться на дефис. Все незначимые пробелы перед и после данных должны удаляться.
Варианты записи телефона:
+78121234567
88121234567
+7(812)1234567
8(812)1234567
+7(812)123-45-67
8(812)123-45-67
Дата рождения должна быть меньше текущей даты, число месяцев в дате должно быть от 1 до 12, число дней от 1 до 31, причем должно учитываться различное число дней в месяце и високосные года. (В третьей подзадаче для обработки даты как вариант можно использовать классы QDateEdit или QCalendarWidget)
E-mail должен содержать в себе имя пользователя состоящее из латинских букв и цифр, символ разделения пользователя и имени домена(@), а также сам домен состоящий из латинских букв и цифр. Все незначащие пробелы (включая пробелы перед и после символа @) должны быть удалены.
Приложение должно позволять добавлять/удалять записи, а также редактировать все поля. Осуществлять сортировку отображаемых данных по указанному полю и поиск по нескольким полям.
Для удобного представления данных пользователю, можно использовать таблицы (см. классы QTableWidget, QTableView) + получаем бесплатную сортировку по полям.

## Build and Run

### Requirements

- C++17 compatible compiler
- CMake 3.16 or later

### Build

```bash
cmake -S . -B build
cmake --build build
```

### Run

```bash
./build/phonebook
```

### Run Tests

```bash
ctest --test-dir build --output-on-failure
```

## Архитектура приложения

### Основные классы и их назначение

| Класс | Назначение |
|---|---|
| Contact | Хранение информации о контакте |
| PhoneNumber | Хранение номера телефона и его типа |
| PhoneBook | Управление контактами, поиск и сортировка |
| Validator | Проверка корректности вводимых данных |
| IContactStorage | Общий интерфейс хранения контактов |
| FileStorage | Сохранение и загрузка контактов из файла |
| DatabaseStorage | Работа с базой данных PostgreSQL |
| ConsoleUI | Консольный интерфейс |
| MainWindow | Графический интерфейс Qt |

### Архитектурные решения

- Для хранения коллекции контактов используется 'std::vector'.
- Каждый контакт имеет уникальный идентификатор.
- Контакт может содержать произвольное количество телефонных номеров.
- Классы 'FileStorage' и 'DatabaseStorage' наследуются от 'IContactStorage'.
- Выбор способа хранения данных осуществляется в функции 'main()'.
- Пользовательский интерфейс отделён от основной логики приложения.

### Соглашения об именовании

- Поля объектов класса имеют префикс 'm_'.
- Для обеспечения инкапсуляции поля классов объявляются в секции 'private'.
